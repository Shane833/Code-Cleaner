# **CodeCleaner**
A simple CLI tool for removing comments from source code

## **Usage**
> **python ccleaner.py [options] [filepath(s)]**

### options
| Option |               Output                  |
|--------|---------------------------------------|
|   -i   | flags to make changes in the same file|
